# ControlGastos-main

Sitio público para GitHub Pages.

## Archivos
- `index.html`
- `style.css`
- `script.js`
- `expenses.json`

## Qué muestra
- Resumen por mes
- Total Personal / Negocios / Ambos
- Filtro por mes
- Historial con fecha de compra, fecha de agregado y fecha de edición
- Miniaturas de facturas

## Importante
Este repo es el **público**. El panel admin separado debe escribir aquí el archivo `expenses.json` y subir imágenes en `receipts/`.
